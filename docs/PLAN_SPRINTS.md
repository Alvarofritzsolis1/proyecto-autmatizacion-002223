# Hitos de GALANT 2.0

1. **Fundación** — React/Vite, FastAPI, PostgreSQL, autenticación, archivos privados y Docker: código incorporado, CI pendiente de validar.
2. **OCR inicial** — nativo y Tesseract local, validación básica de período y RUT: código incorporado, falta corpus real.
3. **OCR avanzado** — reconstrucción de planillas Previred, Isapre/Fonasa; RapidOCR con benchmark de costo y precisión: pendiente.
4. **Plataforma visual** — módulos de carga separados, dashboard, contratistas, historial y visor PDF: interfaz implementada, requiere build y validación E2E.
5. **Inteligencia** — chat contextual para explicar errores con revisión humana y controles de privacidad: pendiente.
6. **Operación 24/7** — instalación Ubuntu, HTTPS, backups y recuperación: scripts preparados; ejecución real en VPS pendiente.
7. **Criterio de producción** — auditoría de seguridad, protección de datos, benchmark, restauración probada, rollback y monitoreo: pendiente.

**Nunca** interpretar código creado, CI verde o Docker activo como certificado de precisión OCR o confirmación bancaria.
